YOLO CRAFT
MINIMALIST FINE-TUNING TOOLKIT
Teach your YOLO model the objects that matter to you.

Pretrained models miss your objects.

A generic YOLO model has never seen your product, your lighting or your camera angle. It guesses with low confidence or finds nothing at all.

The fix is not a bigger model. It is better data from your own scene.

1. Capture the hard frames.

  • Run the baseline on a webcam, video file or RTSP stream.
  • A frame is saved when nothing is found or confidence is too low.
  • Keys: S saves, A toggles auto-capture, Q quits.
$ python -m yolo_craft capture --source 0
capture
conf 0.31
SAVED TO
data/raw/

2. Label in seconds.

  • Drag a box around each object and pick its class.
  • Save the frame, mark it as background or undo the last box.
  • The labeler splits everything into a ready YOLO train/val dataset.
$ python -m yolo_craft label

3. Fine-tune your model.

  • Starts from yolov8n.pt and learns from your labeled images.
  • Loss, learning-rate schedule and augmentation are tunable from the command line.
  • The best checkpoint lands in outputs/runs/train/weights.
$ python -m yolo_craft train --epochs 150
train
EPOCH 1/150LOSS ↓ mAP ↑

4. Test and compare.

  • Try the new model on a webcam, video, image or a whole folder.
  • Export annotated images plus YOLO txt or JSON detections.
  • Benchmark shows baseline and fine-tuned side by side.
$ python -m yolo_craft benchmark
before / after

AFTER: FOUND

Close the loop.

The active command runs capture and label in one go. Every round fixes what the model was weakest at, so the dataset grows exactly where it matters.

$ python -m yolo_craft active

Export. Ship anywhere.

  • One command builds every deployment format.
  • Plot training curves and write a REPORT.md automatically.
  • Zip the dataset to share or back it up.
$ python -m yolo_craft export --format all
